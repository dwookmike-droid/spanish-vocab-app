## 4. Production rules
- Fonts are embedded and subset, with **0 Type 3**. If a glyph is missing from a font (→ ★ in Caveat/Special Elite/Jost; · — º ñ in Nanum Pen), draw it in SVG or replace the character.
- Photos are real (Wikimedia Commons CC0 / PD / CC BY / CC BY-SA), **≥300ppi at placed size**, and only resampled down. Openers need originals of at least 2480×3508px after crop.
- Ornaments (tape, stamps, tags, posters, chalkboards) are vector SVG/CSS. Shadows use zero blur so they stay vector.
- Labels are ≥7pt.
- Props are generic, with no real logos. Stamps, tickets and boarding passes carry **no dates or seats**. If they ever do, mark them "decorativo".
- Each chapter folder has a CREDITS.md. The printed book needs a credits page for BY/BY-SA.
- Pronunciation follows IPA from Wiktionary. Korean transcription conventions: p/t/c → ㅃ/ㄸ/ㄲ, b/v → ㅂ, ll/y → 이·야 sounds, j → ㅎ, z/ce/ci → ㅅ (seseo). The stressed syllable is in bold.
