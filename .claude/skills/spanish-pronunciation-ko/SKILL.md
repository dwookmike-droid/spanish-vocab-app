# 스페인어 → 한글 발음 표기 (단어장 규칙)

검증기 `tools/validate_text.py`가 아래 규칙을 기계적으로 확인해요. 규칙은 v6 인쇄본(60단어)에서 점검을 마친 것이에요.

## 자음
| 스페인어 | 표기 | 예 |
|---|---|---|
| p | ㅃ | pelo → **뻴**로, champú → 참**뿌** |
| t | ㄸ | tijeras → 띠**헤**라스 |
| c(a·o·u), qu, k | ㄲ | cuchara → 꾸**차**라, maquinilla → 마끼**니**야 |
| c(e·i), z | ㅅ | cepillo → 세**삐**요, taza → **따**사 |
| f | ㅍ (f만 ㅍ) | grifo → **그리**포, semáforo → 세**마**포로 |
| b, v | ㅂ | lavabo → 라**바**보 |
| d | ㄷ (어말 d는 약하게, 표기는 드 또는 생략 — 사전 IPA 확인) | inodoro → 이노**도**로 |
| g(a·o·u), gu(e·i) | ㄱ | grifo, águila → **아**길라 |
| j, g(e·i) | ㅎ | jabón → 하**본**, higiénico → 이**히에**니꼬 |
| h | 소리 없음 | horno → **오**르노 |
| ch | ㅊ | ducha → **두**차 |
| ll, y(+모음) | 야·예·요·유 | toalla → 또**아**야, billete → 비**예**떼 |
| ñ | 냐·녜·뇨·뉴 | bañera → 바**녜**라 |
| r(어중), rr | ㄹ | jarra → **하**라 |
| l(어말) | ㄹ 받침 | papel → 빠**뻴** |
| s(어말) | 스 | dientes → **디엔**떼스 |
| x | ㄱㅅ | taxi → **딱**시 |
| ㅋ, ㅌ | 쓰지 않음 | |

## 모음과 이중모음
- a e i o u → 아 에 이 오 우. ie → 이에, ue → 우에, ei → 에이, au → 아우.
- 강세가 이중모음에 오면 두 글자를 함께 감싸요: dientes → **디엔**떼스, aeropuerto → 아에로**뿌에**르또.

## 강세 `**…**`
- 사전(위키낱말사전 en.wiktionary의 스페인어 IPA, ˈ 표시)으로 강세 음절을 확인해요.
- 내용어마다 정확히 1개. 관사·전치사·접속사(el la los las un una de del a al en con y o por para sin lo)에는 표시하지 않아요.
- 강세가 받침 있는 음절이면 받침까지 감싸요: andén → 안**덴**, secador → 세까**도르**.
- 표기 단위는 한글 음절이에요. 한 음절 단어는 그 음절 전체: tren → **뜨렌**.

## 띄어쓰기
스페인어 단어 수와 같게 띄어요. `la tabla de cortar` → `라 **따**블라 데 꼬르**따**르` (4단어 = 4덩이)

## 자주 하는 실수
- p를 ㅍ으로(파스타 ✗ → **빠**스따 ✓)
- t를 ㅌ으로(토마테 ✗ → 또**마**떼 ✓)
- ll을 ㄹ로(또알라 ✗ → 또**아**야 ✓)
- h를 소리 내기(호르노 ✗ → **오**르노 ✓)
- z·c(e·i)를 ㅈ·ㅆ으로 섞기 → ㅅ으로 통일(스페인 발음은 영어 th에 가깝다는 설명은 책 앞쪽 범례에 있어요)
